# Incident Report: Faculty Lounge Coffee Machine

**Date:** 2019
**Status:** Under review

At approximately 8:52 a.m. the coffee machine made a sound described by witnesses as "a sigh, but in a minor key." It has not dispensed coffee since. It has, however, continued to display the message READY, which the committee considers misleading.

Further questions about the coffee machine should be directed to no one.
