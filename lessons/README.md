# Lesson Order

The professor follows this order. Slice 1 lessons are marked **[S1]**, Slice 2 **[S2]**, Slice 3 **[S3]**, Slice 4 **[S4]**.

**The order:** 0.1 → … → 2.4 → path choice → all of 3A or all of 3B → 4.1 … 4.5. Graduation isn't written yet; lessons without a script file are skipped (see the `/next-step` skill), so the course currently ends at 4.5. Learners who skipped a lesson before it was written are offered it when they return (see `/start-course`).
