# Lesson 0.1: Welcome to the Department

- **Module:** 0 (shared)
- **Time:** ~10 min
- **Request budget:** ~5 agent requests (estimate; verify in free-tier testing)
- **Last tested:** 2026-10-23, QA pass 1 (David). Fixes applied; needs a retest.

## Goal

The learner opens a file, asks the AI a question about it, and gets a useful answer. **Their first win in under 10 minutes.**

## Why it matters to a psychologist

Most of a psychologist's admin day is reading things and figuring out what to do about them. The first thing to learn is that the AI can read files with you.

## Setup

- `world/artifacts/welcome-email.md`
- Before starting, the tutor checks that `workspace/progress.md` exists. If it doesn't, the learner probably opened the wrong folder (see sticking points).
- The tutor must be able to edit files (not in **Ask** mode). `/start-course` checks this.

## UI this lesson depends on

See `lessons/CURSOR_UI.md`: opening a file (**Files** → folders → file); the **Ask** tag (if present, remove it).

## Steps

1. **Name.** Ask what they'd like to be called, and record it in `progress.md`. *Why:* the tutor remembers things by writing them in files. (Don't explain more yet. It pays off in Lesson 2.2.)
   - ✅ **Checkpoint:** their name is in `progress.md`.

2. **Find the welcome email.** Tell them the course's files and folders live in the **Files** list, like a filing cabinet. Give the steps from "Open a file" in `lessons/CURSOR_UI.md`: click **Files** (then **Browse Files** if it appears), open `world`, then `artifacts`, then click `welcome-email.md`. Don't say where on the screen **Files** is. Name it by its label. *Why:* everything the AI works with is a file you can see.
   - ✅ **Checkpoint:** they say the email is open. Ask who it's from. **Expected answer: Dr. Miriam Okafor** (the chair; shown in the From line and the signature). Read the file to confirm before replying. If they're close but misspell it ("Okefor"), accept it and use the correct spelling: *"Yes, Dr. Miriam Okafor, the department chair."* Never offer a different name.

3. **Read it.** Give them a minute to skim it. It's short and a little silly. That's on purpose.

4. **Ask the AI about it.** Have them type into the chat in their own words something like: *"What do I actually need to do this week, based on the welcome email?"* Let them write their own version. The point is that **they** typed it.
   - ✅ **Checkpoint:** they've sent a question and gotten an answer.

   When you answer their question, answer it well: a short list (orientation in the Annex 3B, meet Jordan, forms to Priya, don't ask about the coffee machine).

5. **Name the moment.** Right after you answer their question, say what they just did, in two or three sentences: *"That's a core way to use an AI assistant. You gave it a document, asked a question in your own words, and it pulled out what you needed. You didn't have to search the email or phrase anything in a special way. Everything else in this course builds on that."* Don't skip this step. The takeaway is the lesson.

6. **Cost note (brief, honest).** In two or three sentences: this course aims to run on Cursor's free plan. Each message uses a little of the free allowance, so the tutor will keep things short. If they ever hit a limit, Cursor's low-cost paid plan finishes the course. No need to worry about it now.

7. **First pause point.** One sentence: *"You can stop any time. When you come back, type `/start-course` and you'll pick up exactly where you left off."* Then offer to continue to 0.2. (Lesson 2.2 explains how this works.)

## Pause points

- End of lesson (step 7). The first time the learner experiences put-down / pick-up.

## Done when

Their name is recorded, they've opened a file by clicking it, and they've asked the AI a question about that file in their own words.

## Common sticking points

- **The tutor sees no `workspace/progress.md`** → they likely opened the parent folder or the ZIP's outer folder. Help them use Open Folder to open the folder containing `README.md` and `lessons/`.
- **"I don't see Files"** → the project panel may be hidden. See `lessons/CURSOR_UI.md`: the panel-toggle icon at the top corner of the window shows it. If they're in the IDE layout, the file explorer is a different panel. Ask them to describe what they see.
- **The chat is in Ask mode** (a green **Ask** tag in the message box) → you can't save progress. Have them click the × on the tag and type `/start-course` again. Don't say "switch to Agent mode."
- **Their checkpoint answer doesn't match what you expect** → read the file again before correcting them. You may be the one who's wrong.
- **They're anxious about "doing it wrong"** → reassure them: nothing in this lesson can break anything, and everything can be undone.

## Avoid

- Don't introduce modes, @-mentions, rules, or the terminal. That's later.
- Don't summarize the email for them before they ask.
- Don't over-celebrate. Be warm and brief.
