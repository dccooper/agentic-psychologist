# Lesson 2.3: Build Your First Skill

- **Module:** 2 (shared)
- **Time:** ~25 min
- **Request budget:** ~8 agent requests (estimate; verify in free-tier testing)
- **Last tested:** Antigravity 2.5.5, QA pass 3: passed, no errors. Revised from the tester's notes; retest in the final end-to-end run.

## Goal

The learner builds **`/meeting-to-actions`**, a skill that turns any meeting transcript into action items using their template and rule. They run it on a new meeting and improve it once. **This is the course's milestone:** download to first skill.

## Why it matters to a psychologist

Psychologists run the same procedures again and again: intake, scoring, supervision notes, lab updates. A skill is a written procedure the AI follows the same way every time, like a protocol or a manual. Writing one is how "the AI helped me once" becomes "the AI does this for me every week."

## Setup

- `world/artifacts/clinic-staff-meeting.md` (a new meeting: the Daybreak Clinic staff meeting, Thursday the 6th)
- `workspace/templates/action-items.md` and `.agents/rules/my-style.md` (from 2.1). **If either is missing**, the skill can describe the format directly. Note it, and carry on.
- **Skill file format:** a skill is a folder in `.agents/skills/` with a `SKILL.md` inside, starting with frontmatter. `description` is required; it's how the AI knows when to use the skill.
  ```
  ---
  name: meeting-to-actions
  description: Turn a meeting transcript into action items in my format. Use when I type /meeting-to-actions or ask for action items from a meeting.
  ---
  ```
  ⚠️ *Verify in testing whether a new skill shows up as a `/` chip right away or only in a new conversation.*
- **Expected answers for the clinic meeting (for the tutor):**
  - **Priya**, book the group room for the open house, by Friday (the 7th) · **Jordan**, make the open house flyer, "before the open house" (the 22nd; vague, should be flagged) · **Dr. Reyes**, personally invite Dr. Osei and the family practice, this week · **Priya**, reprint intake forms with the new phone number, by Monday (the 10th) · **Jordan**, send the updated supervision schedule, **no date** ("once I've checked with everyone").
  - **Unassigned:** look through the blue binders for the website password.
  - **Decisions:** open house Saturday the 22nd, 2–4 pm; refreshments from the bakery, not the coffee machine.
  - **Must not appear:** anything about the client Jordan started to mention. (There are no details in the transcript. The point is that the action items shouldn't mention it at all.)

## UI this lesson depends on

See `lessons/SCREEN_GUIDE.md`: the Explorer (inside `.agents`); reviewing and accepting a new file; editing by hand; **+** for a new conversation; **skills in the message box** (typing `/` plus a skill name turns it into a chip); **@** to attach a file.

## Steps

1. **A new meeting.** Jordan has forwarded the clinic staff meeting ("lol same thing again pls"). Have them open `world/artifacts/clinic-staff-meeting.md` and skim it. *"You could do 1.4 all over again. Or you could teach the AI to do it your way, permanently."*

2. **What's a skill?** One or two sentences: *"A skill is a written procedure the AI follows when you call it by name, like `/next-step`, which you've used all course. Today you write one."*

3. **Describe the procedure.** Ask them to say, in their own words, the steps they'd want the AI to follow every time. Help them get to roughly:
   1. read the transcript I attach;
   2. pull out action items in my template's format (follow my rule: owner and date, never guess);
   3. list decisions separately;
   4. save to `workspace/actions/` with the meeting's name;
   5. finish by telling me what's unassigned, so I can chase it.
   - ✅ **Checkpoint:** they've described at least four of these steps in their own words.

4. **Draft the skill.** Have them ask the AI to create `.agents/skills/meeting-to-actions/SKILL.md` from their description, **with the frontmatter shown in Setup** (`name` and `description`). Write it; they review it **closely** before accepting, because this file will run every time. *Why:* the AI can draft the skill, but you're responsible for what it says.
   - ✅ **Checkpoint:** read the file. It's in the right folder, starts with `name` and `description` frontmatter, and its steps match their description (template, rule, decisions, save location, unassigned list).

5. **Make it yours.** Have them change at least one line of `SKILL.md` by hand: a step's wording, the save location, the order. Save. **Pause point.**
   - ✅ **Checkpoint:** read the file and confirm a learner edit.

6. **Run it.** **Before they go**, tell them: *"New skills only show up in a new conversation. If it still isn't there when you type `/meet`, close Antigravity completely and open it again. When it's done, type `/next-step` in that conversation and we'll carry on."* Then have them start a **new conversation** (the **+**), type `/meet` and press **Tab** to fill in the rest (✅ Tab completes skill names), attach `@clinic-staff-meeting.md`, and send. When it's done, they review and accept the new file, then type `/next-step`.
   - ✅ **Checkpoint:** read the saved file and compare with the expected answers in Setup: their format, the five owned items, the blue-binder password **unassigned**, the two decisions, and **nothing about the client**. Check the file name and location match what `SKILL.md` says, too.
   - **If it didn't do what they expected** (wrong file name, skipped a step, ignored the template): this is a gift, not a failure. Have them ask the AI, in their own words, to compare what it did with what `SKILL.md` says and explain the gap. Then fix the skill together and rerun. *"That's how you debug an agent: compare what it did with what it was told."* (✅ QA pass 3: this happened, and the diagnosis and fix worked well.)

7. **Improve it once.** Ask: *"What would you change about the skill?"* If they're unsure, offer three:
   - **Vague dates:** "if a date is relative ('before the open house'), give the real date if the transcript says it, and flag it either way."
   - **A chase list:** "end with a short 'Questions to chase' list for anything unassigned or undated."
   - **Privacy:** "if a transcript mentions a client, leave it out of the action items completely, and tell me you did."

   Have them make the change in `SKILL.md` (by hand or by asking the AI and reviewing it), then run the skill again on the same meeting.
   - ✅ **Checkpoint:** the skill file has their improvement, and the second result shows it.

8. **Name the part.** One line, tying to 2.2: *"That's a **skill**. With your rule from 2.1 (**instructions**) and the notes it saves (**memory**), you now have all three parts of an agent."*

9. **Name the moment.** Two sentences: *"You built a tool that does your work your way, every time, and you improved it like any procedure. That's the milestone this course was built around: from download to your first skill."*

## Pause points

- After step 5 (the skill is written and theirs).
- End of lesson.

## Done when

`.agents/skills/meeting-to-actions/SKILL.md` exists with `name` and `description` frontmatter and at least one learner edit; it has run on the clinic meeting and saved a result in `workspace/actions/`; it's been improved once and run again.

## Common sticking points

- **The skill runs but doesn't follow its own steps** → see step 6: ask the AI to compare its result with `SKILL.md`. Common causes: a step is vague ("save it somewhere"), the skill and the rule disagree, or the request in chat contradicted the skill.
- **`/meeting-to-actions` doesn't show up as a chip** → check that the folder name is `meeting-to-actions` and the file is exactly `SKILL.md` inside it, with frontmatter at the very top. Try a new conversation. If it still isn't there, have them close Antigravity completely and reopen it (✅ a Mac tester needed this; **File → Open Recent** if the course folder doesn't reopen). As a fallback, they can type *"Use the meeting-to-actions skill on @clinic-staff-meeting.md."* Note what happened in `progress.md` for the course authors.
- **The skill ignores the template** → check that the skill names the template's path (`workspace/templates/action-items.md`). Skills only know what's written in them, or in the rules.
- **The result includes the client mention** → a perfect moment for the privacy improvement in step 7.
- **"Why not just keep asking in chat?"** → you could, and you'd get a slightly different result each time, and you'd have to remember what to ask. A skill is the same procedure every time, and anyone can read it.

## Avoid

- Don't write the procedure in step 3 for them. Help them get there with questions.
- Don't skip the close review in step 4. A skill runs every time, so mistakes in it repeat.
- Don't add other skills in this lesson. One good skill beats three rough ones.
