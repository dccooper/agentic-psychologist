# Lesson 2.1: Templates and Rules

- **Module:** 2 (shared)
- **Time:** ~20 min
- **Request budget:** ~6 agent requests (estimate; verify in free-tier testing)
- **Last tested:** Antigravity 2.5.5, QA pass 3: passed, no errors. Revised from the tester's notes; retest in the final end-to-end run.

## Goal

The learner saves their action-items format as a **template**, writes a **rule** the AI follows in every conversation, and sees the AI use both **without being reminded**.

## Why it matters to a psychologist

Every practice and lab has "the way we do it here": note formats, email tone, what never gets guessed. Writing that down once, where the AI reads it every time, saves the explaining and makes the output consistent. It's the AI version of a style guide or a clinic policy binder (the one you can actually find).

## Setup

- `workspace/meeting-actions.md` (the learner's finished action items from 1.4). **If it's missing**, have them describe their preferred format instead and build the template from that.
- `workspace/my-rule.md` (the data rule they wrote for *themselves* in 0.2, used as a callback)
- `world/artifacts/jordan-survival-guide.md` (the test material in step 5; its "things to do week 1" list has no owners and only one date, **"by friday"** for the supervision sign-up)
- **Rule file format (Antigravity):** rules live in `.agents/rules/` as `.md` files. ✅ *QA pass 3:* when a file in `.agents/rules/` is open, Antigravity shows an **Activation Mode** setting at the top of it: **Manual**, **Always On**, **Model Decision**, **Glob**. That setting is stored as a short header at the top of the file:
  ```
  ---
  trigger: always_on
  ---
  ```
  **Use the toggle, don't type the header.** Typing it as well makes a duplicate. A rule with no activation mode is silently ignored. (In another editor with no toggle, type the header by hand.) ⚠️ *Still to confirm: whether the toggle writes the header to disk itself.*

## UI this lesson depends on

See `lessons/SCREEN_GUIDE.md`: New Folder / New File in the Explorer (inside the `.agents` folder); editing and saving by hand; reviewing and accepting a new file; **+** for a new conversation; **@** to attach a file.

## Steps

1. **The repeat problem.** One or two sentences: *"In 1.4 you explained your format to the AI. Next week you'd have to explain it again, and again. Today you write it down once."*

2. **Make a template.** Have them ask the AI to turn `@meeting-actions.md` into a **blank template** at `workspace/templates/action-items.md`: the same layout and headings, with placeholders instead of real tasks. They review and accept it.
   - ✅ **Checkpoint:** read `workspace/templates/action-items.md`. It has the learner's layout and **no real action items** from the meeting.

3. **A rule for yourself, a rule for the AI.** Callback: *"In 0.2 you wrote a rule for yourself in `my-rule.md`. A rule for the AI is the same idea, written where the AI reads it every time."*

4. **Write the rule by hand.** Have them create the folder `rules` inside `.agents` (right-click `.agents` → **New Folder…**), then the file `my-style.md` inside it. With the file open, have them find **Activation Mode** at the top and choose **Always On**. Then **they type** two or three rules in their own words. They should cover:
   - how they like writing to sound (e.g., "plain language, short sentences");
   - "action items always have an owner and a due date; if either is missing, write *unassigned* or *no date*, never guess";
   - "when I ask for action items, use the format in `workspace/templates/action-items.md`."
   - *Optional:* add the gist of their 0.2 rule ("if I'm about to share client information, stop me and remind me why"), so the AI backs them up.

   Save. *Why Always On:* the activation mode tells Antigravity when to use the rule. Always On means every conversation. With no mode set, the rule is silently ignored. (The other modes switch a rule on only when you ask for it, when the AI judges it relevant, or for certain files. Always On is all they need.)
   - ✅ **Checkpoint:** ask what **Activation Mode** shows (expected: **Always On**), and read `.agents/rules/my-style.md`: it has the owner/date rule and points to the template. If the file has **two** `trigger:` headers, have them delete the one they typed. **Pause point.**

5. **Test it without mentioning it.** **Before they go**, tell them: *"A new conversation doesn't know you're mid-lesson. When you've got the result, type `/next-step` there and we'll carry on."* Then have them start a **new conversation** (the **+**) and ask: *"Turn the 'things to do week 1' list in @jordan-survival-guide.md into action items and save them to `workspace/week-1-actions.md`."* **Nothing about the format, the template, or the rule.**
   - ✅ **Checkpoint:** read `workspace/week-1-actions.md`. Expected: **their template's layout**, the supervision sign-up **due Friday**, and everything else marked **no date** (not invented dates). The owner is the new student (them), or unassigned.

6. **Name the part.** One line, as a preview of the next lesson: *"A rule is part of an AI's **instructions**: what it should do every time, without being asked. Next lesson, you'll open the instructions that have been running this course."*

7. **Name the moment.** Two sentences: *"The AI followed your format and your rules without being reminded, because you wrote them down where it looks. Any preference you find yourself repeating is a candidate for a template or a rule."*

## Pause points

- After step 4 (the rule is written).
- End of lesson.

## Done when

`workspace/templates/action-items.md` exists; `.agents/rules/my-style.md` exists, set to **Always On**, with the owner/date rule; and, in a fresh conversation, the AI saved `workspace/week-1-actions.md` in their format and didn't invent dates, without being told to.

## Common sticking points

- **The rule doesn't seem to apply** → check, in order: **Activation Mode** says **Always On** (and there's only one `trigger:` header in the file); the file is saved (no dot on the tab); it's in `.agents/rules/`, not `.agents/skills/` or `workspace/`; and the test ran in a **new** conversation. If it still doesn't apply, note it in `progress.md` for the course authors.
- **They can't find `.agents`** → see the 2.2 sticking point: folders starting with a dot are sometimes hidden.
- **The AI invents dates anyway** → good teaching moment. Rules make good behavior more likely, not guaranteed. Reviewing still matters (1.1).
- **They write a rule that changes how the professor teaches** (e.g., "always give me the answer") → explain gently that rules apply to every conversation in this folder, including the professor. Keep rules about *their writing*, and leave the teaching rules to `AGENTS.md`.

## Avoid

- Don't write the rule file for them. Typing the rules and choosing the activation mode themselves is part of the lesson.
- Don't open `AGENTS.md` or explain skills yet. That's the reveal in 2.2.
- Don't mention the template or rule when they run the test in step 5.
