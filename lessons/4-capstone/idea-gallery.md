# Idea Gallery

*Pick one, mash two together, or invent your own. Start small: what's a 20-minute first version? None of these use patient data.*

| For | Idea | Builds on |
|---|---|---|
| Clinicians | **Psychoeducation handout generator**: a topic and a reading level in, a handout out | Skills, templates (2.1, 2.3) |
| Clinicians | **CE credit and license-renewal tracker** | Memory, handoffs (3A.2) |
| Clinicians | **Practice website or referral one-pager** | 3A.3 |
| Clinicians | **Workshop or talk prep agent** | Skills (2.3) |
| Clinicians | **Supervision prep agent**: agenda and readings, *no case details* | Memory (3A.2) |
| Researchers | **Weekly literature digest** from papers you drop in a folder | 3B.2 |
| Researchers | **Grant timeline and task agent** | Memory, handoffs |
| Researchers | **Codebook or data dictionary builder** for public or approved data | 3B.3 |
| Researchers | **Lab onboarding guide** for new RAs | Templates, skills |
| Researchers | **Papers in LaTeX**: write in Markdown, the agent builds the formatted paper and you iterate on the layout *(new; every reference must be a real paper you've read)* | 3B.3a, 3B.2a |
| Students | **Comps or licensing-exam study buddy** that quizzes you from your notes | Skills |
| Students | **Internship application tracker** with essay feedback | Memory |
| Students | **Dissertation sprint planner**: chapter milestones, small daily targets, and a handoff that records the exact sentence to write next | Pick up, put down |
| Anyone | **Expand your chief of staff or lab agent** (from 4.1) | 3A.2 / 3B.2 |
| Anyone | **Tech support helper**: explain an error message, a spreadsheet formula, a settings problem, before fixing anything *(new)* | 1.2 read, think, act; 2.4 |
| Anyone | **Taste board**: collect examples of work you admire, have the agent describe the pattern, reuse it as instructions *(new)* | 3A.3a taste step |

⚠️ **Near the line:** some ideas can drift toward protected data. Practicum-hour logs often include client initials; a tech-support request might involve a work laptop holding patient records. Check your go-live checklist before you start.
