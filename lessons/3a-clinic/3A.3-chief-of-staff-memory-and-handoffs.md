# Lesson 3A.3: Build a Chief of Staff: Memory and Handoffs

- **Module:** 3A (clinic)
- **Time:** ~20 min
- **Request budget:** ~8 agent requests (estimate; verify in free-tier testing)
- **Last tested:** Antigravity 2.5.5, QA pass 4: passed. Revised from the tester's notes; retest in the final end-to-end run.

## Goal

The learner adds `/meeting-prep` and a **`/wrap-up` skill that writes a handoff note** to the chief of staff's memory. They close the conversation, open a fresh one, and watch the chief of staff pick up where it left off. **Pick up, put down, built into their own agent.** They shape both skills by telling the AI, in their own words, what to change.

## Why it matters to a psychologist

The hardest part of busy professional work is continuity: what did we decide, what's next, who was I meant to call? A handoff note is the same idea as a good shift handover or a clear progress note, applied to your own admin. Once the agent writes it for you, you can stop mid-week and lose nothing.

## Setup

- `world/artifacts/referral-partners.md` (five partners for Wednesday's lunch; Dr. Osei didn't know about assessments; the school counselor's question went unanswered; Hilltop Pediatrics stopped referring)
- From 3A.2: `workspace/clinic/chief-of-staff/instructions.md`, `memory/`, and `.agents/skills/weekly-plan/SKILL.md`. **If they're missing**, go back to 3A.2 first.
- **New skills need a new conversation.** ✅ *QA pass 4:* typing `/wrap-up` right after creating it, in the same conversation, showed nothing. So this lesson **creates both skills first** (steps 2 and 3), then runs both in **one** new conversation (step 4). Never ask them to run a skill in the conversation that created it.
- **The recipe, file by file (for the professor):** `/meeting-prep` and `/wrap-up` = **skills**. `memory/handoff.md` = **memory**. Name the part each time a file is made.
- **Scaffold less than in 3A.2.** Ask *"What should it do?"* and *"What would you change?"* first. Use the lists below to check their answer, not to hand it to them. Offer options only if they're stuck.
- **Expected meeting prep (for the professor):** a one-pager for Wednesday's community partners lunch that lists who's coming (Riverside, the school counseling office, the University Counseling Center, Community Health Collective; Hilltop is a maybe), what to say to each (assessments for Dr. Osei; wait times for Mr. Adeyemi; current hours for Dr. Park; Spanish-language availability for Rosa Medina; ask Hilltop why referrals stopped), Daybreak's one-line offer, the open house invitation (Saturday the 22nd, 2–4), **and the clash with Jordan's case review at 12:30.**

## Steps

1. **The problem.** *"Your chief of staff is smart for one conversation. Close it, and it only knows what's in its files. Today you'll make it leave itself a note."* One line callback: *"Same as `progress.md` for the professor. Which part of the recipe is that?"* (Expected: **memory**.)

2. **`/meeting-prep`.** Have them open `world/artifacts/referral-partners.md` and skim it. Ask: *"What should a meeting-prep skill do for Dr. Reyes?"* Let them answer in their own words, then have them ask the AI to create `.agents/skills/meeting-prep/SKILL.md` from that. Check it against this list. If something's missing, ask a question that leads them there rather than adding it. It should: read `instructions.md` and `memory/` first; read the meeting details and attendee list it's given; produce a one-page prep (who's coming, last contact, one thing to say or ask each, what we offer, logistics and conflicts); save it to `workspace/clinic/chief-of-staff/prep/`.
   - Before they accept, have them ask the AI *"Is anything missing from this?"* Point it out if the AI suggests something on its own. Then: *"What would you change?"* They tell the AI, and review.
   - ✅ **Checkpoint:** read `SKILL.md`. It reads the instructions and memory first and covers the parts above. One line: *"That's a **skill**."*

3. **`/wrap-up`: the handoff note.** *Why:* the agent can't remember. It can only read. So it writes down what the next session needs. Ask: *"At the end of a work session, what would you want the agent to write down for next time?"* Then have them ask the AI to create `.agents/skills/wrap-up/SKILL.md` from their answer. Check it does these (ask, don't add):
   1. read `instructions.md` and `memory/`;
   2. write `memory/handoff.md`: **what happened this session, what's next, open questions**, with today's date (overwrite the old one, keep it short);
   3. update `memory/projects.md` with anything done or new;
   4. tell the user, in one line, what it saved.

   Same habit as before: *"Is anything missing from this?"*, then they tell the AI what to change.
   - ✅ **Checkpoint:** read `SKILL.md`. It writes `handoff.md` with the three parts and updates `projects.md`. One line: *"Another **skill**, and this one writes **memory**."*

4. **Run both in a new conversation.** One line on why: *"New skills only show up in a new conversation, so we'll run both there, one after the other."* **Before they go**, tell them: *"First run `/meeting-prep`, then `/wrap-up`, in that new conversation. When both are done, type `/next-step` there and we'll carry on."* Then:
   1. New conversation (**+**). Type `/meet` + **Tab** (pick **meeting-prep**), and ask it to prep Wednesday's community partners lunch with `@referral-partners.md` and `@reyes-calendar.md`. They review and accept.
   2. In the **same** new conversation, type `/wrap` + **Tab** and send. They review the two changed files.
   - ✅ **Checkpoint (prep):** read the prep and compare with the expected answers in Setup. Ask: *"What should Dr. Reyes say to Dr. Osei?"* (Expected: that Daybreak does assessments, and hand her the open house invitation.) Did it notice the 12:30 clash?
   - ✅ **Checkpoint (handoff):** read `memory/handoff.md`. It says meeting prep for Wednesday is done, and names next steps (e.g., resolve the 12:30 clash, deliver Dr. Osei's invitation).
   - If either result isn't what they wanted, ask *"What would you change?"* They tell the AI to fix the skill, then rerun it in a new conversation to be safe. (⚠️ *Whether an edited skill updates in a conversation that's already open is unverified.*)
   - **Quick knowledge check:** *"Which part of the recipe is `handoff.md`? And `/wrap-up` itself?"* (Expected: `handoff.md` is **memory**; `/wrap-up` is a **skill**.) One line of praise or a one-line correction.
   - **Pause point.**

5. **Put it down, pick it up.** **Before they go:** *"When you've seen the result, type `/next-step` there."* Have them start **another new conversation** (**+**) and run `/weekly-plan` with `@reyes-calendar.md` again. They should **not** mention the meeting prep.
   - ✅ **Checkpoint:** the new plan reflects the handoff: Wednesday's prep is done (or marked ready), and the 12:30 clash is still flagged. Ask: *"How did a conversation that never saw your meeting prep know about it?"* (Expected: the handoff note in `memory/`, read by step 1 of the skill.)

6. **Name the parts.** One line: *"Instructions, skills, and memory, all yours. The handoff note is the memory part doing what `progress.md` did for you all course."*

7. **Name the moment.** Two sentences: *"You can now stop your chief of staff mid-week, close everything, and pick up exactly where you left off, because it writes its own handoff note. That's pick up, put down, built into an agent you made."* Teaser: *"In the capstone, you'll make this yours."*

## Pause points

- After step 4 (both skills built and run; the handoff note exists).
- End of lesson.

## Done when

`/meeting-prep` and `/wrap-up` exist, shaped by the learner's own instructions to the AI, and have run in a new conversation; `memory/handoff.md` has what happened / what's next / open questions; a fresh conversation's `/weekly-plan` reflected the handoff without being told.

## Optional stretch

**`/whats-slipping`:** a skill that reads the memory and today's date and lists what's overdue, what has no next step, and what appears on more than one list. They describe it, ask *"Is anything missing?"*, then run it once **in a new conversation**. (Expected: the Dr. Osei invitation and the Ward, Locke & Key reply.)

## Common sticking points

- **`/wrap-up` or `/meeting-prep` doesn't show up** → it's being run in the conversation that created it. Start a new conversation (**+**). Also check the folder name matches and `SKILL.md` is inside it.
- **The new plan ignores the handoff** → check `/weekly-plan`'s step 1 says to read *every* file in `memory/`. If it names only `projects.md` and `people.md`, have them tell the AI to add `handoff.md`. A good debugging moment: forgets → memory.
- **`/wrap` + Tab finds the wrong skill** → keep typing (`/wrap-u`) or pick from the list.
- **The handoff note is very long** → have them tell the AI: "five lines or fewer." Short notes get read.
- **They're stuck on what to change** → only now offer options, e.g. "make the prep fit on one screen," "add a line for who hasn't been contacted in a year," "put the clash at the top."
- **They worry about the skill count** → four skills is a small, normal agent. Each one is a short text file.

## Avoid

- No client information in any prep, plan, or note.
- Don't run a skill in the conversation that created it.
- Don't write their skill descriptions or offer options before they've had a go. They decide and direct; the AI executes.
- Don't tell them to type `/next-step` between ordinary steps. Just ask *"Ready to move on?"* (New conversations in steps 4 and 5 are the exception.)
- Don't add more skills than the lesson asks for (the stretch is optional).
- Don't skip the fresh-conversation test. It's the point of the lesson.
