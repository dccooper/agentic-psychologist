# Lesson 3B.2b: Build a Lab Agent: Memory and Handoffs

- **Module:** 3B (lab)
- **Time:** ~20 min
- **Request budget:** ~7 agent requests (estimate; verify in free-tier testing)
- **Last tested:** not yet tested

## Goal

The learner adds `/weekly-lab-update` and a **`/lab-wrap-up` skill that writes a handoff note** to the lab agent's memory. They close the conversation, open a fresh one, and watch the lab agent pick up where it left off. **Pick up, put down, built into their own agent.**

## Why it matters to a psychologist

Research runs for months, and people come and go: RAs graduate, postdocs move on, you go to a conference and forget what you'd decided. A lab that writes things down survives that. A handoff note is the agent version of a good lab notebook entry: what happened, what's next, what's open.

## Setup

- `world/artifacts/lund-friday-update.md` (Dr. Lund wants a weekly update: done, next, stuck, "three lines is plenty")
- From 3B.2a: `workspace/lab/lab-agent/instructions.md`, `memory/`, `lit-matrix.md`, and `.agents/skills/lit-matrix/SKILL.md`. **If they're missing**, go back to 3B.2a first.
- **Firewall (tutor):** same as 3B.2a. No papers outside `data/reading-pack/`.
- **Expected weekly update (for the tutor):** three short lines, from memory only. **Done:** first-pass lit matrix of five papers (three on EFT and delay discounting). **Next:** read full texts of the three relevant papers; analysis question with Dr. Bello. **Stuck / needs a decision:** "more references" means someone has to find and read real papers first; the pack doesn't support "EFT works for depression."

## UI this lesson depends on

See `lessons/SCREEN_GUIDE.md`: reviewing new files; **+** for a new conversation; skills (Tab completes names); **@**.

## Steps

1. **The problem.** *"Your lab agent is smart for one conversation. Close it, and it only knows what's in its files. Today you'll make it leave itself a note."* Callback: *"Same as `progress.md` for the tutor."*

2. **`/weekly-lab-update`.** Have them open `world/artifacts/lund-friday-update.md`. Then have them describe a weekly-update skill and ask the AI to create `.agents/skills/weekly-lab-update/SKILL.md`. It should: read `instructions.md` and `memory/` first; write **three lines (done / next / stuck)** from memory only, no new claims; save it to `workspace/lab/lab-agent/updates/` with the date. They review it.
   - ✅ **Checkpoint:** read `SKILL.md`. It reads instructions and memory first, and the three-line format is there.

3. **Run it.** **Before they go:** *"When it's done, type `/next-step` there."* New conversation (**+**), `/week` + **Tab** (pick **weekly-lab-update**), send. They review and accept.
   - ✅ **Checkpoint:** read the update and compare with the expected update in Setup. Ask: *"Did it promise anything that isn't in memory?"* (e.g., "five more references found." That would be invented.) **Pause point.**

4. **`/lab-wrap-up`: the handoff note.** Have them ask the AI to create `.agents/skills/lab-wrap-up/SKILL.md`. When run, it should:
   1. read `instructions.md` and `memory/`;
   2. write `memory/handoff.md`: **what happened this session, what's next, open questions**, with today's date (overwrite the old one, keep it short);
   3. update `memory/projects.md` and `memory/reading-list.md` with anything done or new;
   4. tell the user, in one line, what it saved.

   *Why:* the agent can't remember. It can only read. So it writes down what the next session needs.
   - ✅ **Checkpoint:** read `SKILL.md`. It writes `handoff.md` with the three parts and updates the other memory files.

5. **Run `/lab-wrap-up`.** In this conversation, `/lab` + **Tab**, send. They review the changed files.
   - ✅ **Checkpoint:** read `memory/handoff.md`. It records the matrix and the weekly update as done, and the open questions (more references, the depression claim).

6. **Put it down, pick it up.** **Before they go:** *"When you've seen the result, type `/next-step` there."* New conversation (**+**). Have them ask, in their own words, something like *"What should I work on next for the lab?"* using `/weekly-lab-update` or just plain language. **They shouldn't explain what happened before.**
   - ✅ **Checkpoint:** the answer reflects the handoff note (the matrix is done; full texts and the analysis question are next). Ask: *"How did a conversation that never met you know that?"* (Expected: the handoff note in `memory/`, read first by the skill.)

7. **Name the parts.** One line: *"Instructions, skills, and memory, all yours. The handoff note is the memory part doing what `progress.md` did for you all course."*

8. **Name the moment.** Two sentences: *"You can now stop your lab agent mid-project, close everything, and pick up exactly where you left off, because it writes its own handoff note. The AI speeds up reading; your notes and your checking are what make the work trustworthy."* Teaser: *"In the capstone, you'll make this yours."*

## Pause points

- After step 3 (weekly update done).
- End of lesson.

## Done when

`/weekly-lab-update` and `/lab-wrap-up` exist and have run; `memory/handoff.md` has what happened / what's next / open questions; a fresh conversation picked up from the handoff without being told.

## Optional stretch

**`/paper-summary`:** a skill that writes a one-page summary card for a single paper in the pack (question, sample, design, finding, limits, "not stated" items), saved to `workspace/lab/lab-agent/summaries/`. Run it on one paper. The same citation rules apply.

## Common sticking points

- **The fresh conversation doesn't know anything** → check the skill's step 1 reads *every* file in `memory/`, including `handoff.md`. If they asked in plain language without a skill, the AI may not have read the lab agent's memory. Try again with `/weekly-lab-update`. Good debugging moment.
- **`/week` + Tab finds the wrong skill** → keep typing (`/weekly-l`) or pick from the list. (If they also did the Clinic path, `weekly-plan` is there too.)
- **The update is long** → Dr. Lund will read three lines. Ask for three.
- **The update says progress was made that wasn't** → compare it with memory. Agents fill gaps optimistically; the instructions should say "from memory only."

## Avoid

- No papers outside the reading pack (firewall).
- Don't add more skills than the lesson asks for (the stretch is optional).
- Don't skip the fresh-conversation test. It's the point of the lesson.
