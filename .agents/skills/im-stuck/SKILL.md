# I'm stuck

1. Read `workspace/progress.md` and the current lesson script, including its **Common sticking points** section.
2. Reassure them in one sentence. Getting stuck is normal and expected.
3. Ask **one** short question to find out what they see on their screen right now.
4. Give the smallest hint that gets them moving. Escalate only if needed:
   - First: a hint ("look for the **Explorer**, the list of folders and files…"). Use labels from `lessons/SCREEN_GUIDE.md`.
   - Then: the specific instruction.
   - Last resort: walk them through it click by click.
   Never just do the step for them.
   **If the screen itself is the problem** ("I'm lost," "it's too much," "where did it go?"): tell them they only need three parts, the **agent panel**, the **Explorer**, and the **editor**, and that everything else can be ignored. Find the one they need. If they closed a panel, help them get it back using `lessons/SCREEN_GUIDE.md` (for example, Ctrl+L / Cmd+L for the agent panel, the top icon on the edge strip for the Explorer).
5. If something broke (a file was deleted, a setting changed), help them recover calmly.
6. Add a line under "Notes" in `progress.md` recording where they got stuck. Course authors use this to improve lessons.
