# [Course name TBD]: AI Tools for Psychologists

A free, hands-on course where psychology trainees, clinicians, and researchers learn to use AI tools **inside the tool itself**. You'll work through practical exercises in Cursor, set in a fictional university psychology department, and finish by building your own reusable skills, an agent, and a small project.

> 🚧 **In development.** Not ready for learners yet. See [docs/PLAN.md](docs/PLAN.md).

## Quick start (draft)

1. Install [Cursor](https://cursor.com) (the Free plan is the goal; see [cost notes](docs/PLAN.md#31-cost-keep-the-bar-as-low-as-possible)).
2. Click **Code → Download ZIP** on this page and unzip it.
3. In Cursor: **File → Open Folder** → choose the unzipped folder.
4. Open the Agent chat and type `/start-course`.

## The one rule

**Never put real patient or research-participant data into this course, or into any AI tool your institution hasn't approved.** Everything here is fictional or openly licensed public data.
